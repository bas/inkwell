# Settings

Open **Settings** with the gear button on the left side of the titlebar.

## Features

The **Features** section controls optional tools in the app.

| Feature    | What it controls                                                                    |
| ---------- | ----------------------------------------------------------------------------------- |
| **Labels** | Label grouping, label chips, the per-note label picker, and global label management |

## Labels

Turning **Labels** off hides label-related UI but does not delete label data. Existing labels remain in note frontmatter and reappear if you turn Labels back on.

When Labels is enabled, the **Labels** section in Settings lets you create labels, change their colours, and delete labels.

## AI model

The **AI model** section controls which Copilot model Inkwell uses for new AI requests.

- **Auto (Recommended)** lets Copilot route each request to the best available model.
- You can pick an explicit model from the available list when you want predictable behavior.
- If the selected model becomes unavailable, Inkwell automatically falls back to **Auto**.
